# helpz — a toolbox of little `*z` system scouts

> *Auto-generated by `publishz` on 2026-10-28 — 56 tools, always in sync with the code.*

Small, single-file Bash diagnostics for Linux: security audits, hardware
probes, network forensics, driver & firmware health, kernel care, power
analysis. No dependencies beyond coreutils; optional tools (`jq`, `bc`,
`nvidia-smi`, `lspci`, `systemd`) light up extra sections when present.

## Why `*z`?

The trailing `z` can never shadow a system command — `cpuz` ≠ `cpu` — and the
whole library lives in one folder you drop on your `PATH`.

## Install

```bash
git clone <your-fork-url> helpz && cd helpz
export PATH="$PWD:$PATH"       # or: ln -s "$PWD" ~/.local/bin/ztools
./helpz                        # meet every tool
```

## Highlights

- **`kernelz`** — kernel study & *safe* upgrades: new kernel boots once, GRUB's
  permanent default stays on the last known good one (auto-recovery on a bad
  boot), `verify` promotes it, `protect` makes `apt upgrade` kernel-proof,
  `bench` compares kernels side by side, and `fix` is a package doctor that
  names the exact missing packages + one-line fix.
- **`driverz`** — driver & firmware auditor with plug-event timeline
  (`--events`), live plug diagnosis (`--watch`), device lookup cards
  (`driverz 0bda:8179`), per-chip playbooks for network, video and audio,
  and apt recommendations verified against your repos.
- **`powerz`** — battery/GPU diagnostics + `--accuracy`: audits its own watt
  and $/year estimates against RAPL/battery counters, graded A–D over time.
- **`secretz`** — system credential auditor plus `--code DIR` repo scanner:
  run it on any project before you publish.
- **`pushz`** — a secret/leak gate in front of `git push`: it scans the
  outgoing tree and refuses to publish credentials or personal paths.
- **`depz`** — dependency doctor: finds the optional helpers the suite wants
  and installs the ones your distro can provide.
- **`chartz`** — text-mode charts for any data you pipe into it.
- **`helpz`** — self-documenting: drop a new `*z` script in and it appears
  automatically (keep the `# name - desc` + `#   ./name ...` header style).

## Privacy & safety

- Reports written by the tools (`*-reports/`, `*.txt`) are git-ignored.
- `ai.json` is git-ignored — ship `ai.json.example` instead.
- Nothing phones home; network calls exist only in the explicitly
  network-focused tools, and only to targets you name.
- `pushz` and `clonez` guard the edges: nothing leaves without a secret
  scan, and nothing lands without one either.
